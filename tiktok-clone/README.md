# TikTok Clone — полнофункциональный клон

Современный клон TikTok, сделанный на чистом HTML/CSS/JS без фреймворков. Выглядит и ощущается как настоящий TikTok Web.

## ✨ Фичи

- 📱 Вертикальная лента с snap-скроллом (как в TikTok)
- ▶️ Авто-плей/пауза через IntersectionObserver
- ❤️ Двойной тап / клик для лайка с анимацией burst
- 🔇 Глобальный mute/unmute
- 💬 Комментарии (drawer)
- 🔗 Поделиться (модалка)
- ➕ Загрузка своих видео (drag & drop, file picker, публикация в ленту)
- 👤 Профиль с сеткой видео
- 🔍 Поиск по хэштегам, юзернейму, описанию
- 📑 Вкладки Рекомендации / Подписки
- ⌨️ Горячие клавиши: ↑↓ навигация, L лайк, M звук, Esc закрыть
- 📊 Прогресс-бар видео, счетчики лайков/комментов/шаров
- 🎵 Бегущая строка с названием трека
- 📱 Адаптив: десктоп (3 колонки) → планшет (сайдбар иконки) → мобила (нижний таб бар, полноэкранное видео)

## 🚀 Запуск

Просто открой `index.html` или запусти статический сервер:

```bash
cd tiktok-clone
python3 -m http.server 5173
# или
npx serve .
```

Открой http://localhost:5173

## 🧩 Технологии

- Vanilla JS (ES Modules)
- CSS Grid / Flex, scroll-snap, backdrop-filter
- IntersectionObserver для видимости видео
- Object URLs для загруженных видео

## 📁 Структура

- `index.html` — разметка
- `styles.css` — стили в стиле TikTok (темная тема, #FE2C55 / #25F4EE)
- `app.js` — логика ленты, лайков, подписок, модалок

Сделано с ❤️ как демо-проект.
